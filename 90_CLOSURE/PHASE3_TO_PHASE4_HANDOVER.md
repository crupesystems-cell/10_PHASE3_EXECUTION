# Handover: Phase 3 -> Phase 4

## Fixed Baseline (Phase 3)
- Governance-first enforcement active
- Determinism gate enforced
- Protected main branch
- Linear history required
- PR-only integration
- No bypass, no force push
- Single-maintainer mode (no approvals)

## Phase 4 Focus
- Stabilization: reproducibility, operational hardening
- Scaling: contributor model, approval policy, rulesets
- Investor readiness: audit narrative, risk register, TD snapshot

## Explicit Phase-4 Decisions Required
- Multi-contributor model (enable / keep single)
- Approval requirement (0 vs 1+)
- Migration to repository rulesets (yes / no)
- Release discipline (tags, changelog cadence)
